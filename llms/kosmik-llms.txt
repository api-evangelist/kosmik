# Kosmik

> Kosmik was an infinite-canvas visual workspace and moodboarding app for macOS and Windows,
> built by Lithium Media SAS in Paris. It combined a spatial canvas ("universes" grouped into
> "workspaces") with a built-in web browser, web clipper, PDF reader, real-time multiplayer
> collaboration, and AI features (auto-tagging, AI search, AI asset discovery). Kosmik shipped
> no public API, SDK, CLI or webhook surface. The product sunset on 2026-05-31; the vendor now
> publishes data-export instructions in place of any migration interface.

## Status

- Product status: sunset (end of life 2026-05-31)
- Wind-down and data export: https://www.kosmik.app/0-wind-down-export

## Notes

- No OpenAPI, AsyncAPI, GraphQL or gRPC definition is published, so no specs, overlays,
  error catalog, data model, conventions, scopes, agent skills or MCP server can be derived.
- The pricing page listed "MCP integrations" as a coming-soon feature of an unreleased
  "Ambassador" plan. It never shipped and the product has since sunset, so no MCPServer
  artifact is claimed.
